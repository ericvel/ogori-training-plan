# Ogori training plan

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

One runner, using phone and computer before and after runs. Private Cloudflare Access sign-in, restricted to `eric.vel@outlook.com`, with a one-month Access session. Online-only; progress syncs across devices.

## Product Purpose

Train for the Ogori Half Marathon on March 14, 2027, aiming for under 1:35. Continue the existing 21-week plan, preserving session IDs, progress, and notes.

## Operating Context

Two core runs and an optional third run per week, with flexible run days and fixed week ranges. Garmin Connect activity-overview CSVs are uploaded in the app. Activities named week3coreA, week3coreB, or week4optional link automatically to sessions. Coaching and plan changes are discussed in chat, never generated by the app.

## Capabilities and Constraints

- Current-week home, race countdown, full plan, expandable workout details.
- Completed/skipped status, actual run dates, inline single-line autosaved notes.
- Activity history, weekly running-distance totals, manual session links, automatic name matching, duplicate-safe reimports.
- Tagged optional runs missing from the original plan appear as extra completed runs in their named week.
- Kilometres, min/km, Asia/Tokyo; CSV timestamps have no offset.
- Portable backup of plan, progress, notes, activities, and links.
- Existing Vue project, Cloudflare Pages, Functions, D1, and Cloudflare account login through Access; target free tiers. Main-branch updates auto-deploy through existing GitHub integration.
- No offline queue, multi-user features, or in-app coaching.

## Brand Commitments

Calm, compact, light interface with restrained color, readable instructions, and large phone controls. Keep Core run A/B and Optional labels, week ranges, autosave, and inline notes. Avoid repetitive placeholders and a separate save-status section.

## Evidence on Hand

Legacy local-tracker schedule.json and progress.json contain 61 sessions over 21 weeks and seven completion flags, with no notes or actual completion dates. Preserve these without inventing dates. Confirmed overview-10-11-26.csv contains 15 running activities and 25 columns, eight session tags (one is an extra Week 2 optional run). Six older activities from an earlier export are unavailable and may be imported later.

## Product Principles

- Put this week's training first.
- Preserve history across imports and plan revisions.
- Let names establish intended session links; keep actual dates factual.
- Make save/import failures visible and recoverable.
- Keep personal data outside public source and static assets.
